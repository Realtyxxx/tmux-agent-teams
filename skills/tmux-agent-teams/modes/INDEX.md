# Scenario Mode Index

Use this index to match a user's requested team workflow to an optional mode.
Read only the selected mode's `MODE.md`; use the generic protocol when no row
matches.

| Mode             | Trigger                                                                                                                                                                |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fix-feature-mr` | A Leader coordinates multiple Workers who each own an isolated worktree and branch for a fix or feature, deliver an MR/PR, and track review through merge and closure. |
